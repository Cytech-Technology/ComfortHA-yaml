# Home Assistant App: Cytech AI Assistant

---

## Overview

The Cytech AI Assistant answers questions about your Comfort system from inside
Home Assistant. It reads the live state of this Home Assistant — entities, recent
history, and recent warnings and errors — and explains what it sees.

It is designed for both **owners** and **installers**:

- Owners can ask what a status means and what to do next.
- Installers can ask it to read entity states, history, and log errors while
  troubleshooting on site.

The assistant is **read-only**. It cannot arm or disarm the alarm, bypass zones,
activate outputs, run scripts or services, change settings, edit dashboards, or
write any file. It only observes and explains.

---

## Requirements

- Home Assistant OS with internet access.
- The **Cytech Comfort** App installed, so the Comfort entities exist.
- An **installation token** issued by Cytech or your installer. The token is
  entered once in this App's configuration.

The panel is available to any Home Assistant user with access to the sidebar
item. It does not require an administrator account.

## Installation

1. Go to **Settings → Apps**, then **Install App**.
2. Click **⋮ (three dots)** in the top-right corner → **Repositories**.
3. Add `https://github.com/Cytech-Technology/ComfortHA-yaml`.
4. Install **Cytech AI Assistant**.
5. Open the App's **Configuration** tab:

   | Option | Value |
   |---|---|
   | `installation_token` | The token supplied by Cytech or your installer. |
   | `model` | Leave on **Sonnet 5.5** unless Cytech advises otherwise. |
   | `proxy_url` | Leave as `https://ai.cytech.biz` unless Cytech advises otherwise. |

6. Start the App. A new **AI Assistant** entry appears in the Home Assistant
   sidebar.

   On Home Assistant OS with Supervisor 2026.11 or later, the sidebar entry is
   a per-user setting: if it does not appear, open the App's page and turn on
   **Show in sidebar**. Older Supervisors add it automatically.

If the token field is empty, the panel opens with a setup notice and the chat is
disabled until a token is entered.

## Using the assistant

Type a question in the box at the bottom and press **Enter** (use **Shift+Enter**
for a new line). While an answer is being prepared, the panel shows what it is
reading — for example "Reading an entity" or "Scanning the Home Assistant log".

- **New chat** clears the conversation and starts fresh.
- **Stop** ends the current answer. The partial answer stays on screen.
- The line under the input shows how much of this installation's monthly AI
  allowance has been used.

Example questions:

- "Is my alarm in trouble?"
- "Which zones are open, and since when?"
- "How is my system health?"
- "The alarm panel says disarmed, but the keypad shows Trouble. What is going on?"
- "Show me the errors in the Home Assistant log for the Comfort add-on."

Follow-up questions keep the conversation context, up to 20 questions, after
which a new conversation starts automatically.

### Good to know

- Answers are generated by an AI service. They can be wrong. The assistant shows
  the entity values it used so you can check them.
- If a value is stale or unavailable, the assistant should say so. If it does not,
  ask it which entity it read.
- The assistant explains how you can do something; it never does it for you.

## Privacy and security

- **Read-only:** the App only issues GET requests to the Home Assistant core
  API, plus the read-only `system_log/list` command over the websocket API when
  the log-file endpoint is unavailable. There is no code path that writes, calls
  a service, or controls a device.
- **No chat storage on Cytech servers:** the `ai.cytech.biz` relay stores a hash
  of the installation token and monthly token counts. It does not store prompts,
  answers, entity data, or IP addresses.
- **Local conversation storage:** the current conversation is kept in the App's
  local data folder on your Home Assistant device, so it survives an App
  restart. It is pruned after 7 days and **New chat** deletes it.
- **Message processing:** prompts and the Home Assistant data the assistant reads
  are processed by Anthropic's Claude API on Cytech's account, in order to produce
  the answer.
- **Secrets:** never type passwords, alarm codes, Home Assistant credentials,
  remote-access links or QR codes, or anything from `cytech_secrets` into the
  chat. The App redacts common credential patterns from logs and entity
  attributes before they reach the model, but the safest rule is not to type
  them.
- **Exposure:** the panel is reachable only through Home Assistant ingress; no
  extra port is opened.

## Models and allowance

Two models are available in the `model` option:

- **Sonnet 5.5** (default) — the most capable option, best for troubleshooting.
- **Haiku 4.5** — faster and uses less of the allowance, for simple questions.

No other model is permitted. Each installation has a monthly allowance, by
default 300 service requests per month, resetting on the first day of each
month (UTC). The panel shows the requests used. A question that needs the
assistant to look at several entities uses more than one request. When the
allowance is used up, the assistant explains when it resets. Contact Cytech if
you need a higher allowance.

## Troubleshooting

| What you see | What it means | What to do |
|---|---|---|
| "This assistant is not set up yet" | No installation token in the App configuration. | Enter the token from Cytech or your installer, then restart the App. |
| "The AI installation token is not valid" | The token was mistyped or has been replaced. | Ask Cytech or your installer for the current token and re-enter it. |
| "AI access for this installation has been revoked" | Cytech has disabled the token. | Contact Cytech support. |
| "The monthly AI allowance ... is used up" | Quota reached for this month. | Wait for the reset date shown, or contact Cytech. |
| "The AI service cannot be reached right now" | The Home Assistant device has no internet access, or the service is down. | Check the network, then try again. |
| "Home Assistant rejected the add-on's access" | The App was started without a valid Supervisor token. | Restart the App; if it persists, reinstall it. |
| Chat works but Comfort entities are missing | The Comfort App is not installed or is not running. | Check the Cytech Comfort App and its logs. |

App logs: **Settings → Apps → Cytech AI Assistant → Log**. The logs never
contain the installation token or conversation content.
